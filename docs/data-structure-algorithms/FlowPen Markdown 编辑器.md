# FlowPen Markdown 编辑器

这是一个功能强大的 Markdown 编辑器，专为中文内容创作者设计，完美支持微信公众号排版。

## 核心功能

### 1. 多种主题样式

FlowPen 提供了 20+ 种精美的主题样式，从专业的技术蓝到活泼的萌绿，总有一款适合你的内容风格。

### 2. 实时预览

所见即所得，编辑的同时实时查看渲染效果，让创作更加流畅自然。

### 3. 自定义 CSS

对于有特殊排版需求的创作者，我们提供了自定义 CSS 功能，让你的文章与众不同。

### 4. 丰富的工具栏

支持快速插入常用 Markdown 语法，包括标题、列表、代码块、表格等元素，提高创作效率。
